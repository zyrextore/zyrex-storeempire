# ZYREX V16 — Vercel
1. Push this folder to GitHub.
2. Import the repo into Vercel.
3. Framework Preset: Other.
4. Build Command: leave empty.
5. Output Directory: leave empty.
6. Deploy.
7. Add Environment Variables: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, AI_API_KEY, AI_API_URL, AI_MODEL, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, ADMIN_EMAIL, ADMIN_PASSWORD_HASH.
8. Redeploy.
Never put secrets in frontend JavaScript.
