# ZYREX V14.3 — ALL FIXED

This build is designed to be stable both locally and on Render.

## Local development
- Run backend from `backend/` with `npm install` then `npm start`.
- Backend defaults to `http://localhost:3000`.
- If Supabase variables are absent, the backend automatically uses `backend/data/db.json` for development.
- Local admin credentials: `admin@zyrex.local` / `admin123`.
- Local payment proofs are stored in `backend/data/uploads/`.

## Production / Render
Set `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_EMAIL`, and either `ADMIN_PASSWORD_HASH` or `ADMIN_PASSWORD`.
Set `AI_API_KEY`, `AI_API_URL`, `AI_MODEL` for AI.
Set `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` for Telegram notifications.

## Telegram
Payment proof sends a Telegram photo with APPROVE / REJECT buttons. Configure Telegram webhook to:
`https://YOUR-RENDER-DOMAIN/api/telegram/webhook`

## Single Render service
The backend serves `../frontend`, so one Render Web Service can host the complete website, API, admin, AI proxy and payment flow.
Build: `npm install`
Start: `npm start`
Root directory: `backend`
