# ZYREX V14.2 — Telegram Payment Notifications

Add these Render environment variables:

TELEGRAM_BOT_TOKEN=<BotFather token>
TELEGRAM_CHAT_ID=<your admin Telegram chat ID>

Optional webhook:
POST https://YOUR-RENDER-DOMAIN/api/telegram/webhook

The backend sends:
- new order notification
- payment-proof image + order details
- inline APPROVE / REJECT buttons
- decision confirmation

Never put the bot token in frontend JavaScript or GitHub.
