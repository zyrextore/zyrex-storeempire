# ZYREX V8 ULTRA — Visual Overhaul

This release is a deliberately large visual redesign, not a small theme tweak.

## Major visual changes
- Full-screen cinematic hero with stronger hierarchy and layered grid/glow system.
- Fixed top marquee / ecosystem ticker.
- Premium glass header and liquid navigation dock.
- Animated orbit system and futuristic core visual.
- Large editorial typography with gradient chrome treatment.
- Responsive bento-style project cards with varied spans.
- Glassmorphism store, service, metrics, quote and contact blocks.
- Stronger mobile layout and spacing.
- AI chat and account/payment UI retained.
- Existing backend/API/Store/Supabase architecture retained.

## Deploy
The project remains compatible with the V7.1 one-click Render structure. Keep secrets in Render Environment Variables; never commit `.env` or API keys.
